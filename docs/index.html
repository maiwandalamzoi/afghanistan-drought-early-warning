Drought Watch Afghanistan

Predicting next-month drought status for all 34 Afghan provinces from this month's Sentinel-1 radar, MODIS vegetation/temperature, and CHIRPS rainfall — a real one-month-ahead forecast, evaluated honestly against a naive baseline.

Results · model comparison

Which model actually catches droughts?

Trained on 2015–2021, tested on 2022–2023 — years the model never saw, and a much more drought-heavy period than training (30.8% vs. 11.2% drought-next). Recall on the drought class matters more than accuracy here: missing a real drought is worse than a false alarm.

Honest read: this is a hard problem. The naive "next month = this month" baseline is tough to beat — only LightGBM matches it on F1; Random Forest and XGBoost actually do worse. Logistic regression trades precision for real recall gain (0.747 vs. baseline's 0.581) — more true droughts caught, more false alarms too. No model is declared "the" winner here: that trade-off is an operational policy decision, not a modeling one.
Results · feature importance

What actually predicts next month's drought

XGBoost feature importance. Current conditions dominate (drought is autocorrelated month to month), but radar contributes real, independent signal.

Sentinel-1 SAR (vv_db + vh_db, current + lagged) carries ~18% combined — real work from the one feature type this project has that the yield-forecasting companion project doesn't. Radar responds to soil moisture more directly than optical vegetation indices, which only show a moisture deficit after it's already stressed the plants.

Known limitations

Severe test period

2022–2023's drought rate (30.8%) is triple the training period's (11.2%). Real distributional shift, not an easy holdout — but also means these metrics may not represent a typical, less drought-heavy year.

Short record

SAR/NDVI/LST only go back to 2015 (Sentinel-1's real coverage start, verified not assumed). 3,604 rows for 14 features — modest.

Coverage gaps

11 of 108 months have zero Sentinel-1 dual-polarization coverage, mostly in early 2015 — real nulls, dropped at training time, not imputed.

LST ≠ air temperature

Land-surface temperature, not what a thermometer reads — daytime values on bare, sun-heated terrain can exceed 45°C. Correct for LST, disclosed so it isn't mistaken for an error.

Label/feature overlap

Precipitation feeds both the SPI-3 target and a model feature. Some apparent skill is definitionally close to the label — the SAR/NDVI/LST features are the genuinely independent signal.

Not operational

This is a research artifact evaluating whether the signal exists, not a validated early-warning product. No response decision should be based on it.
