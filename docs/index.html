How is the Composite Drought Index calculated? (plain language, then the real methodology)

In plain terms: the score is built from two independent things that both drop when a real drought happens — how much rain actually fell, and how healthy the vegetation looks from orbit. If both agree things are bad, the score drops a lot. A single number, 0 to 100: 100 is healthy, 0 is as bad as this province's own history gets.

The two ingredients, each a real published method, not invented for this project:

  • SPI-3 (Standardized Precipitation Index) — the World Meteorological Organization's standard definition of meteorological drought. Computed from real CHIRPS satellite-rainfall data, fit to this exact province's own 23-year rainfall history.
  • VHI (Vegetation Health Index) — Kogan, F.N. (1995), "Application of vegetation index and brightness temperature for drought detection," Advances in Space Research 15(11). Used operationally by NOAA and FAO. Combines how green the vegetation looks (from MODIS satellite NDVI) with how hot the land surface is (from MODIS temperature), each compared to that same province's own history for that time of year.

Combined: CDI = 0.5 × VHI + 0.5 × SPI-3 (rescaled to the same 0–100 scale). Equal weighting is a disclosed choice — it treats a rainfall-based signal and a satellite-vegetation signal as equally informative, not a tuned or hidden parameter. Category labels (Healthy / Normal / Moderate drought / Severe drought) use VHI's own established operational thresholds (NOAA/STAR: ≤40 = stress, ≤26 = severe).

Honest cross-check: these two ingredients come from completely different satellites measuring completely different things (rainfall vs. vegetation greenness+heat) — and they still correlate at 0.27 across this whole dataset. Real, independent signals agreeing at all is meaningful; a much higher number would actually be suspicious (it would suggest they're not really independent).

What predicts next month (the separate forecast toggle) is a different thing again: a trained LightGBM model, using this month's real satellite radar (Sentinel-1), vegetation, temperature, and rainfall — not VHI or CDI directly. Tested honestly: adding VHI as a model input actually made the trained model worse (more on that in the README), so it's kept as this page's human-readable display number, not fed back into the model.

Monte Carlo scenario simulator

Not one forecast — a distribution

5,000 draws per scenario, resampled from that province's own real 2015–2023 months, stratified by SPI-3 tercile, run through the trained LightGBM model. Risk score: 0 = no drought risk, 100 = certain drought — the model's predicted probability, rescaled.

Results · model comparison

Which model actually catches droughts?

Trained on 2015–2021, tested on 2022–2023 — years the model never saw, and a much more drought-heavy period than training (30.8% vs. 11.2% drought-next). Recall on the drought class matters more than accuracy here: missing a real drought is worse than a false alarm.

Honest read: this is a hard problem. The naive "next month = this month" baseline is tough to beat — only LightGBM matches it on F1; Random Forest and XGBoost actually do worse. Logistic regression trades precision for real recall gain (0.747 vs. baseline's 0.581) — more true droughts caught, more false alarms too. No model is declared "the" winner here: that trade-off is an operational policy decision, not a modeling one.
Results · feature importance

What actually predicts next month's drought

XGBoost feature importance. Current conditions dominate (drought is autocorrelated month to month), but radar contributes real, independent signal.

Sentinel-1 SAR (vv_db + vh_db, current + lagged) carries ~18% combined — real work from the one feature type this project has that the yield-forecasting companion project doesn't. Radar responds to soil moisture more directly than optical vegetation indices, which only show a moisture deficit after it's already stressed the plants.

Known limitations

Severe test period

2022–2023's drought rate (30.8%) is triple the training period's (11.2%). Real distributional shift, not an easy holdout — but also means these metrics may not represent a typical, less drought-heavy year.

Short record

SAR/NDVI/LST only go back to 2015 (Sentinel-1's real coverage start, verified not assumed). 3,604 rows for 14 features — modest.

Coverage gaps

11 of 108 months have zero Sentinel-1 dual-polarization coverage, mostly in early 2015 — real nulls, dropped at training time, not imputed.

LST ≠ air temperature

Land-surface temperature, not what a thermometer reads — daytime values on bare, sun-heated terrain can exceed 45°C. Correct for LST, disclosed so it isn't mistaken for an error.

Label/feature overlap

Precipitation feeds both the SPI-3 target and a model feature. Some apparent skill is definitionally close to the label — the SAR/NDVI/LST features are the genuinely independent signal.

Not operational

This is a research artifact evaluating whether the signal exists, not a validated early-warning product. No response decision should be based on it.
